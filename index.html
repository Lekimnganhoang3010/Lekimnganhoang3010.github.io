Projects

Each project starts with a business question. The repositories hold the code, data dictionaries and write-ups.

  • Grocery Campaign Effectiveness and Retention

    Dunnhumby “The Complete Journey”. Analysis in progress

    Question: do grocery marketing campaigns change how customers shop, and does the change last? I’m working through 2 years of loyalty-card data: 2,500 households and 30 campaigns.

    So far: cleaned the data (2.5M clean transactions, 1.8% of rows removed) and documented every cleaning decision. Early findings show Type A campaigns have double the coupon redemption rate of Types B and C (16.0% vs. about 8%), though redeemers were already heavier shoppers, so redemption alone doesn’t show lift. Next up: spending lift against a matched comparison group, and a model of post-campaign drop-off.

    Code on GitHub

  • Student Stress Factors Analysis

    Group project, IS 507, UIUC

    Question: which parts of student life drive stress, and can we predict who is at risk? Survey data from 1,100 students across 21 factors.

    Finding: about two in three students report at least moderate stress. Logistic Regression (88.18%) and Random Forest (87.73%) predict stress level well, and clustering found three student profiles.

    Recommendation: support the “Overloaded” group first (poor sleep, noisy housing, unmet basic needs), and use a short screening survey built from the reduced feature set to flag at-risk students early.

    Code and report on GitHub

  • Yelp Consumer Review Database

    Individual project, UIUC

    Question: how should review data be structured so analysts can query it reliably? I gathered user requirements, defined entities and business rules, and drew a crow’s foot conceptual model.

    Built: a normalized schema for 9GB of Yelp review data, SQL table definitions, Python insertion programs, data dictionaries, sample queries, an evaluation plan and database administration procedures.

    Code and report on GitHub

  • SEC 13F Data Curator Challenge

    DSRS, UIUC. Top finalist, August 2026

    Question: how can researchers study institutional holdings without parsing raw SEC filings?

    Built: a cached Python pipeline that turned 40 filings from 20 managers into 100K+ validated holdings in a queryable database, with a source-grounded read-only agent on top.
